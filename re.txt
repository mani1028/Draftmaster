**3. Generate Keys & Config**
Run this python one-liner to generate a Fernet Key:
```bash
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
Copy the output. Create a `.env` file (copy from `.env.example`) and paste the key into `FERNET_KEY`.

**4. Setup AI Provider**
- **Option A (Groq):** Get a free API key from [console.groq.com](https://console.groq.com). Set `LLM_PROVIDER=GROQ` and `GROQ_API_KEY=your_key` in `.env`.
- **Option B (Local Ollama):** Install Ollama, run `ollama pull llama3.2:3b`. Set `LLM_PROVIDER=OLLAMA` in `.env`.
